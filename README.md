## 什麼是 skill-store？

這是 James 的 AI 技能公開發佈庫。所有原創 skill 在這裡對外開放，供其他人在自己的 Claude Code、Hermes Agent 或 OpenClaw 環境中使用。

私有工具庫 → [skill-hub](https://github.com/labesclaw-cmd/skill-hub)（內部使用）

## 使用方式

每個 skill 資料夾內都有獨立的 `README.md`，說明安裝步驟與使用方法。

基本流程：

```bash
# 下載單一 skill
git clone https://github.com/labesclaw-cmd/skill-store.git
cd skill-store/<skill-name>

# 依照該 skill 的 README 安裝
```
